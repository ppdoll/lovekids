# 러브키즈 숙제방 💕

아이들의 매일 숙제(국어·영어·수학)를 자동 출제하고, 완료 여부와 점수를 기록하는 가족용 웹사이트입니다.

## 어떻게 동작하나요?

- **출제**: 매일 아이가 과목을 열면 그날의 문제 세트가 자동으로 만들어집니다.
  - 국어·영어 → `data/problems/`의 **문제은행**(학년당 100문제)에서 최근에 안 나온 문제 위주로 출제
  - 수학 연산(＋－×÷) → **코드로 그때그때 생성**. 저장하지 않으므로 마르지 않습니다
    (학년별 고유 조합 2,500~9,000개)
  - 수학 문장제 → **문제은행 + 템플릿 생성을 반씩** 섞어 출제.
    템플릿은 이름·물건·숫자를 바꿔 끼워 학년당 약 3,000개를 만들고, 정답은 숫자에서 계산하므로
    항상 정확합니다. 손으로 쓴 문제와 섞어 문장 틀이 반복되는 느낌을 줄였습니다.
- **연산 연습 설정**: 부모 페이지에서 아이별로 어떤 계산을 낼지 직접 고를 수 있습니다.
  - 더하기·빼기: 자리수(1~4), 올림/빌려주기(내림) 있는 문제로 낼지
  - 곱하기: 문제에 나올 단 (2~9단, 11~19단 중 선택)
  - 나누기: 나머지가 있는 나눗셈을 낼지 (있을 땐 몫과 나머지를 따로 물어봅니다)
  - 조건은 우연에 맡기지 않고 자리별로 만들어 보장합니다. 예를 들어 "올림 없는 두 자리 덧셈"을
    고르면 올림이 생기는 문제는 단 하나도 나오지 않습니다.
- **채점**: 객관식·단답형 모두 즉시 자동 채점. 숫자·분수는 값이 같으면 정답 처리(예: `3/6` = `1/2`).
- **콤보(연속 정답)**: 연달아 맞히면 화면 위에 연속 횟수가 뜨고, 2·3·4·5·7·10연속마다 반응이
  커집니다. 틀리면 0으로 돌아가고, 그날의 최고 연속 기록은 완료 화면에 남습니다.
  새로고침해도 이어집니다.
- **부모가 오늘 숙제 조정**: 부모 페이지 → 오늘 탭에서 과목마다
  **문제 더 내기**(3·5·10문제)와 **다시 시작**(새 문제로 초기화)을 할 수 있습니다.
  - 문제를 더 내면 완료 상태가 풀리고, 다 풀면 다시 완료로 기록됩니다.
  - 다시 시작하면 달력의 완료 기록도 함께 내려가지만, **오답 노트는 남습니다**.
  - 문제를 잘못 추가했을 때도 다시 시작으로 기본 개수로 되돌릴 수 있습니다.
- **기록**: 날짜별 완료 여부, 점수, 연속 달성(🔥 스트릭), 오답 노트가 저장됩니다.
- **부모 페이지**(PIN, 기본값 `0000`): 오늘 현황 / 달력 / 오답 노트 / 아이·문제 수 설정.

## 로컬에서 실행

```bash
npm install
npm run dev
```

→ http://localhost:3000 접속. 데이터는 `.data/store.json` 파일에 저장됩니다.

## 접근 방식: 구글 로그인 또는 가족 코드

두 가지 모드가 있고, 환경변수로 자동 결정됩니다.

| | 구글 로그인 모드 | 가족 코드 모드 |
|---|---|---|
| 켜지는 조건 | `GOOGLE_CLIENT_ID` + `GOOGLE_CLIENT_SECRET` 설정 | 위 값이 없을 때 |
| 부모 | 구글 계정으로 로그인 | `FAMILY_CODE` 입력 |
| 아이 | **아이 전용 링크**(`/k/...`)로 로그인 없이 입장 | 부모와 같은 코드 |
| 데이터 | 계정(가정)마다 완전히 분리 | 한 가정 전용 |

### 구글 로그인 설정하기

1. [Google Cloud Console](https://console.cloud.google.com/) → **API 및 서비스** → **사용자 인증 정보**
2. **OAuth 클라이언트 ID 만들기** → 애플리케이션 유형 **웹 애플리케이션**
3. **승인된 리디렉션 URI**에 `https://<내-주소>/api/auth/callback` 추가
   (로컬 테스트도 하려면 `http://localhost:3000/api/auth/callback` 도 함께)
   - 정확히 어떤 주소를 등록해야 하는지는 배포된 사이트의 **로그인 화면 → "구글 로그인이 안 되나요?"**
     를 누르면 그대로 보여줍니다. `redirect_uri_mismatch` 오류가 나면 여기부터 확인하세요.
4. 발급된 클라이언트 ID/보안 비밀을 Vercel 환경변수 `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` 에 넣기
5. `SESSION_SECRET` 에 아무 긴 문자열을 넣고 재배포

설정 전까지는 기존 가족 코드 방식이 그대로 동작하므로, 배포된 사이트가 갑자기 잠기지 않습니다.
처음 로그인하는 계정은 **기존에 쌓인 데이터를 그대로 이어받습니다**(자동 이전).

### 아이는 어떻게 들어오나요

부모 페이지 → 설정 → **아이 전용 접속 링크**에서 아이마다 링크를 만듭니다.
아이 기기에서 그 링크를 한 번 열고 **홈 화면에 추가**하면 앱처럼 씁니다.
이 링크로 들어온 아이는 **자기 숙제만** 풀 수 있고, 부모님 페이지와 형제의 기록은 볼 수 없습니다.
링크가 새어나갔다고 판단되면 부모 페이지에서 **새 링크로 바꾸기**를 누르면 이전 링크는 즉시 막힙니다.

## Vercel 배포 (외부 접속)

1. 이 폴더를 GitHub에 올리거나 `vercel` CLI/MCP로 배포합니다.
2. **저장소 연동(필수)**: Vercel 프로젝트 → Storage 탭 → **Upstash for Redis**(무료) 생성·연결.
   - `KV_REST_API_URL`, `KV_REST_API_TOKEN`(또는 `UPSTASH_REDIS_REST_URL/TOKEN`)이 자동 주입됩니다.
   - 연동하지 않으면 기록이 저장되지 않습니다(부모 페이지에 경고 표시됨).
3. **가족 코드(권장)**: 프로젝트 → Settings → Environment Variables에 `FAMILY_CODE=원하는코드` 추가.
   - 설정하면 사이트 접속 시 가족 코드를 한 번 입력해야 합니다(1년 유지).
4. 재배포하면 적용 완료.

## 문제은행 관리

- 위치: `data/problems/{ko,en,math}/grade1~6.json`
- 부모 페이지 → 설정 탭에서 학년·과목별 보유량을 볼 수 있습니다.
- 문제가 부족해지거나 새 유형을 원하면 Claude Code에서:
  - "국어 3학년 문제 30개 리필해줘"
  - "6학년 영어에 비교급 문제만 20개 추가해줘"
- 문제 형식(JSON):
  ```json
  {
    "id": "ko3-031",
    "type": "mc",            // "mc"(객관식) 또는 "short"(단답형)
    "q": "문제 텍스트",
    "choices": ["보기1", "보기2", "보기3", "보기4"],  // mc만
    "answer": 0,              // mc: 정답 인덱스 / short: ["정답", "허용답"]
    "explain": "한 줄 해설",
    "tag": "어휘",
    "level": "normal"        // easy | normal | hard
  }
  ```

## 점검 명령

문제를 추가하거나 코드를 고친 뒤 돌려보면 됩니다.

```bash
npm run check:bank
```

- `check:bank` — 문제은행 전체 검사(JSON 형식, 보기 4개, 정답 범위, 중복 문제·중복 정답, 난이도 분포 표)
- `fix:bank` — 중복 정답 정리 등 자동으로 고칠 수 있는 항목 수정
- `check:math` — 수학 자동 생성 문제 검증. **개발 서버(`npm run dev`)를 먼저 켜둔 뒤** 실행하면, 생성된 계산식을 독립적으로 다시 계산해 정답이 맞는지 2000건 이상 확인합니다.
- `check:code` — 가족 코드 잠금 검증. **`npm run build` 후** 실행하세요. 코드 없이 접근이 막히는지,
  그리고 프록시(미들웨어) 계층을 헤더로 건너뛰는 우회 시도가 차단되는지까지 확인합니다.
- `check:word` — 수학 문장제 템플릿 생성기 검증. 문장 속 숫자로 정답을 다시 계산하고,
  **조사가 받침에 맞는지**("지우이는", "2장를" 같은 어색한 문장이 없는지)까지 확인합니다.
- `check:calc` — 부모가 고른 연산 설정(자리수·올림·빌려주기·단·나머지)이 실제로 지켜지는지 검증.
  **개발 서버를 켜둔 뒤** 실행하세요. 생성된 문제를 자리별로 다시 계산해 조건 위반이 없는지 확인합니다.
- `check:isolation` — **가정별 데이터 격리와 아이 권한 검증. 이 프로젝트에서 가장 중요한 검사입니다.**
  **`npm run build` 후** 실행하세요. 두 가지를 확인합니다.
  1. 구조: 앱 코드가 가정 접두사 없는 저장소 함수를 직접 부르지 않는지 (부를 수 없으면 실수도 불가능)
  2. 동작: 서로 다른 두 구글 계정이 상대 아이를 전혀 못 보는지, 아이 링크 세션이 부모 화면·형제
     기록·다른 가정에 접근할 수 없는지, 링크를 새로 발급하면 이전 링크가 막히는지
- `check:parent` — 부모의 **다시 시작 / 문제 더 내기**와 **콤보** 검증. **개발 서버를 켜둔 뒤** 실행하세요.
  완료 기록이 함께 내려가는지, 오답 노트가 중복으로 쌓이지 않는지, 콤보가 끊기고 이어지는지 확인합니다.
- `check:storage` — 저장소 자동 감지 검증. **`npm run build` 후** 실행하세요. Upstash가 넣어주는
  환경변수 이름이 어떤 형태여도 찾아내는지, 실제로 저장·조회가 되는지 가짜 Redis 서버로 확인합니다.

### "저장소가 아직 연결되지 않았습니다"가 뜨면

1. **재배포**가 가장 흔한 원인입니다. Vercel → **Deployments** → 맨 위 배포의 `⋯` → **Redeploy**.
   환경변수는 재배포해야 반영됩니다.
2. 그래도 뜬다면 부모 페이지의 경고문을 보세요. 발견된 환경변수 **이름**이 함께 표시됩니다
   (토큰 값은 절대 표시되지 않습니다). 이름이 하나도 없으면 연결/재배포가 안 된 것이고,
   이름은 있는데 안 잡히면 그 이름을 알려주시면 대응할 수 있습니다.

### 보안 업데이트

가족 코드 잠금은 Next.js의 프록시(미들웨어) 계층에 걸려 있고, 과거 Next.js에는 이 계층을
헤더 하나로 건너뛸 수 있는 취약점(CVE-2025-29927)이 있었습니다. 그래서 데이터를 내려주는
API에서도 가족 코드를 한 번 더 확인하도록 이중으로 막아 두었지만, Next.js 자체를 최신으로
유지하는 것이 가장 확실합니다. 가끔 아래를 실행해 보세요.

```bash
npm audit
```

취약점이 보고되면 `npm install next@latest react@latest react-dom@latest` 후
`npm run build`와 위 점검 명령들을 돌려 확인하고 푸시하면 됩니다.

## 기본 정보

- 부모 PIN 기본값: `0000` (부모 페이지 → 설정에서 변경)
- 아이별로 과목당 하루 문제 수를 0~30개로 설정 (0 = 과목 끄기)
- 날짜는 항상 한국 시간(Asia/Seoul) 기준
